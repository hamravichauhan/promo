DAY 13 / 100: Cache-Control Headers: How to Keep Returning Visitors Instant

Returning visitors should experience zero network requests for static assets.

Key takeaways to apply to your website today:

• 01 / Content-Hash Static Filenames
  Name builds like 'app.8d3f1a.js' so cached files can safely be cached for 1 full year.

• 02 / Set 'Cache-Control: public, max-age=31536000, immutable'
  Tells browsers to never re-download until the file hash changes.

• 03 / HTML Must Be Short-Lived
  Set 'max-age=0, must-revalidate' on HTML so users always receive fresh asset pointers.
