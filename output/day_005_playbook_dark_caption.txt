DAY 05 / 100: Eliminate Layout Shift (CLS): Stop Elements Jumping Around

Cumulative Layout Shift frustrates users and leads to accidental mis-clicks.

Key takeaways to apply to your website today:

• 01 / Always Set Width and Height
  Provide explicit width and height attributes on all images and video embeds.

• 02 / Reserve Skeleton Spaces
  Use CSS min-height on dynamic containers before content finishes loading.

• 03 / Preload Hero Webfonts
  Add rel='preload' for critical fonts so text doesn't pop or swap violently.
